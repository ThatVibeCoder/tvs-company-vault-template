# Architecture

How this vault is built. One page: `Vault Architecture.md`. Read it before you add a page, a folder or a new kind of file.

**What goes here:** the rules for the vault's own shape (the three kinds of page, the log test, which page owns a rule, how a section is shaped, the map of top folders).

**What never goes here:** rules for a job (those live in the skill or how-to page that does the job), notes, logs, or anything about one client.

**Example:** you want to start keeping a list of every post you send. Open `Vault Architecture.md`, run the log test ("will this get a new row every time something happens?"), see it's a log, and point at the platform instead.
