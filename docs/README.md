# Docs

The long reference behind `AGENTS.md`. Nothing here is read up front: `AGENTS.md` names the one section a job needs.

**What goes here:** `REFERENCE.md`: the full table of where everything goes, the shape of a team, a team member and a skill, how shortcuts are built, how a lesson adds a team, and where corrections go.

**What never goes here:** knowledge about your business (`brand/`, `knowledge/`), how-to pages for a job (a skill, or `operations/playbook/`), notes, logs.

**Example:** your AI isn't sure where a new kind of file belongs. It reads "Where everything goes" in `REFERENCE.md`. If it isn't listed, it asks you before making a new home.
