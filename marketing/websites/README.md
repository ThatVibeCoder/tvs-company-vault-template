# Websites

Every site and landing page: what it's for, where its code lives.

**What goes here:** one short page per site: what it's for, its address, and where its code lives (your website repo, `<company>-website`, or the site builder that holds it). The list of every page and the offer it sells is `knowledge/landing-pages.json`.

**What never goes here:** the website's files (they live in the website repo; every save there can put the site live), visitor numbers (read them in Google Analytics and Search Console when you need them).

> **Router rule:** if this company keeps this information somewhere else (Notion, a CRM, a Google Doc), write a pointer to the exact page here instead of copying it, so nothing exists twice. If it lives here, write it here.
