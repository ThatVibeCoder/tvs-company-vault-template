# Hooks

One file per platform. Each hook says where it came from (the owner's own words, a tested post, a competitor) and how it did. Never invent a hook and present it as tested.

**Knowledge, not a log.** Each platform's file holds what works now, kept short: the openers that won for your buyer (the opener, its shape, and the number that made it a winner), the ones to try next, and the ones that lost three times in a row with why. When a list gets long, the weakest one leaves. The posts themselves stay on the platform. (This is the one home for hooks; the old `knowledge/hooks.md` was folded in here. If a skill or lesson still says `knowledge/hooks.md`, write to the platform's file here instead.)

General hook rules: start from `brand/voice.md` and `brand/guidelines.md`.
