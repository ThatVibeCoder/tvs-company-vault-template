# Packs

Packs from the community land here, one folder per team they feed (for example `packs/dev-team/`).

**What goes here:** a pack's knowledge pages: examples, frameworks, reference pages a team reads before a big build.

**What never goes here:** skills (a skill goes inside the team member that owns it, `departments/<department>/<team>/<member>/skills/<skill>/SKILL.md`, then run sync), code that runs (your headquarters repo), keys.

**When a pack arrives:** file it here, then tell the team it belongs to that it exists.
