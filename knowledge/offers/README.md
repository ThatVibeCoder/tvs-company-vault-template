# Offers: what gets delivered

What gets built the moment someone buys each offer. One folder per offer: `README.md` (what the offer is, who it's for), `projects.md` (the projects and standard tasks it creates) and `frameworks.md` (how the work gets done). Copy `_example-offer/` to start one.

**The offer's name and price** live in `brand/offer.md`, or in your CRM/Notion if you keep them there; then `sales/offers/README.md` points to the exact page.
